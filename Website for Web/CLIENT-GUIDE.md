
# Rockstar Rebel Website Guide

## What the website does

This is a simple website for the Rockstar Rebel T-shirt brand. It is made with HTML for page content and CSS for the design. It does not use JavaScript.

## The pages

- `Home.html` is the homepage. It introduces the brand, shows new launches, and has a New Drop section farther down the page.
- `Collection.html` shows 10 men's T-shirts and 10 women's T-shirts.
- `About.html` shares the Rockstar Rebel brand story.
- `NewDrop.html` features the latest T-shirt drop.
- `style.css` controls colors, spacing, image sizes, and how the pages fit different screen sizes.

## How the code works

- `<div>` groups parts of a page together.
- `<ul>` and `<li>` make lists, such as the navigation menu.
- `<a href="Collection.html">` creates a link. The `href` tells the browser which page to open.
- `<img src="..." alt="...">` displays a picture. The `src` is its location; the `alt` text describes it.
- `class="..."` gives an element a name so CSS can style it.
- `id="..."` gives a section a unique name. A link like `href="#women"` jumps to that section.
- `<br>` starts a new line inside text.
- In CSS, `margin` adds space outside an element and `padding` adds space inside it.

## Making common changes

- To change words, edit the text between the HTML tags.
- To change a product picture, replace the image address in that product's `src` value. Keep the `alt` text accurate.
- To change a product name, edit its text in `Collection.html`.
- To change colors or spacing, edit the matching style in `style.css`.
- To change where a link goes, edit its `href` value. The Shop Now links currently open `Collection.html`.

## A note about the products

The product names, prices, and photos are sample content. Replace them with the brand's approved product details and images before publishing. The photos are loaded from the internet, so they need an internet connection to display.

## How to view it

Open `Home.html` in a web browser, then use the menu to visit the other pages.
